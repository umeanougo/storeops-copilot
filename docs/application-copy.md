## Application version — under 1,500 characters

While helping a third-party fulfilment operator examine Shopify workflows, I saw repeated account switching to review orders, payment readiness, line items, exceptions, and unfinished work. The discovery context involved about eight merchant accounts and 24 recurring checks per day.

I independently built and deployed StoreOps Copilot, a multi-merchant fulfilment prototype. It combines an actionable order queue, merchant backlogs, explainable exceptions, and a daily brief while preserving provider, merchant, and store context. Deterministic rules calculate ageing, payment blocks, partial fulfilment, inventory constraints, backlog risk, and priority. A bounded assistant answers supported questions from scoped records and links the evidence.

The optional OpenAI path is deliberately constrained: the server composes the approved answer, and model output is accepted only if every value, sentence, link, identifier, and array position matches. Any deviation uses the deterministic answer. This tests output containment; the model does not perform operational reasoning.

I used AI coding tools for framing, implementation, debugging, testing, and documentation while owning scope, rules, safeguards, validation, and quality. This is independent portfolio work—not a client deliverable, production deployment, measured outcome, or Shopify-endorsed product.
